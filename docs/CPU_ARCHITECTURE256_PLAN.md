# CPU 探索：参数共享 × 独立训练深度

执行前方案日期：2026-10-11。用户授权完成“四组性能对照、按真实标签拆开的错误变化，以及是否值得继续做病灶干预的判断”。本阶段只补齐架构对照并作判断，不执行病灶扰动。此前共享模型结果已观察，本轮是探索，不能称为未知结果的预注册或独立临床确认。

## 探索问题

相同图像特征、模块宽度、处理次数和训练日程下，共享参数是否改变增加深度的良恶性预测收益及错误取舍？观察到的差异是否在两种固定末期学习率下保持，是否涉及恶性/良性错误，而不只是平均概率损失？

| 模型 | 参数结构 | 执行次数 | 可训练参数 |
|---|---|---:|---:|
| UJ2 | 两个独立 Transformer block | 2 | 1,159,394 |
| UJ4 | 四个独立 Transformer block | 4 | 2,049,122 |
| SJ2 | 一个共享 block | 2 | 714,530 |
| SJ4 | 一个共享 block | 4 | 714,530 |

四组分别训练到指定深度，均只监督最终分类/分割输出。四步模型的第二步读出不替代独立两步模型，也不作为内部“纠错”的证明。编码器是共同冻结的 DeiT-Tiny，另有5,717,416参数；本实验比较其后的附加模块，不是端到端普通ViT与全循环ViT的比较。相同深度/宽度不等于相同参数数目或完整训练FLOPs。

继续使用256训练Case（174良性、82恶性、445图），159 tune开发Case（108良性、51恶性、281图），原始清单/编码器/缓存/队列指纹保持一致。Case与患者对应仍未核实，cal/test继续不生成预测。所有视图按Case分组，评估先预测视图再平均Case概率。

种子固定53、71、89、107、131。每个UJ的每个独立block初始数值等于该种子SJ的共享block，分类头、mask头及读出归一化初值一致；独立block参数存储互不共享。记录UJ2/UJ4各自全模型指纹与共同组件指纹，不能误要求不同参数结构的全模型哈希相同。这是控制参数共享的初始化，不是普通网络每层独立随机初始化的全部常规训练选择。

## 预先列出的比较与错误诊断

每种政策分别报告原始未校准最终Case Brier、NLL、AUROC、Dice、0.5阈值的敏感度/特异度。定义：

- A_depth,policy = Brier_UJ − Brier_SJ：相同深度的共享收益。
- G_arm,policy = Brier_depth2 − Brier_depth4：该架构增加深度的收益。
- Theta_policy = G_SJ − G_UJ：共享是否改变深度收益。

三者完整报告；Theta为正不能单独证明SJ4优于UJ4。逐种子列出均值与样本标准差，不集成模型概率。

按真实标签分别拆开错误：恶性FN→TP/TP→FN，良性FP→TN/TN→FP，以及两模型都对/都错；比较同深度UJ→SJ、同架构2→4及同模型恒定→低末期政策。名称使用跨模型预测变化，避免将其说成同一模型内部纠错。另报告每类概率与Brier/NLL变化，高置信假阴性p≤0.05、高置信假阳性p≥0.95（包含边界）。不据此选择或剔除Case。

整体配对bootstrap先在每Case内平均5个种子效应，再重采样159Case，2000次、种子17，条件于已训练网络。真实标签分组的误差/概率效应在51恶性或108良性Case内配对重采样，保留对应分母；不把5次预测当5名患者，也不将这些区间当作种子总体或独立患者总体不确定性。

本轮不新增温度拟合或阈值搜索。既有温度诊断不被当作所有新模型的统一校准对照；概率尺度的完全归因仍有边界。0.5操作点只是内部探索，不能转述为预先选定的临床活检决策阈值。

## 病灶干预是否值得继续

完成后作独立定性审查，依据全部种子、两种政策、真实标签拆分、极端概率及效果是否集中于少数Case。可值得追的是可重复的有益或有害架构特异现象，不能只要求循环取胜，也不能仅凭最好模型或一个平均Brier下降决定。

若普通模型出现相同深度/政策响应，则证据更支持一般深度或优化效应；若只有概率评分变化而没有一致的判别/错误差异，应先收窄概率尺度解释；若现象不一致，保留不确定结论。若存在相对普通模型仍有一致性的良恶性错误差异，才提出后续病灶/邻近区域与远处匹配区域干预，用于验证证据依赖，仍不直接证明循环机制。
