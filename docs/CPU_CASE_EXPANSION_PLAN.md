# CPU 病例扩充：嵌套 128/256 Case 的固定更新预算比较

执行前方案日期：2026-10-11。五个新种子复核已经支持扩充；本轮依据用户授权，首次训练 256 Case 模型，并使用严格匹配的原三个种子参照。方案在观察新模型结果前锁定。

## 研究问题

在相同 3,200 次更新下，将训练 Case 从 128 增至 256，四步相对两步的良恶性预测收益是否保留？更多不同病例、较少重复接触是否改变开发概率误差、诊断排序、轮廓质量和训练/开发差距？

本轮不是单纯增加数据量的因果检验：固定总更新数必然使每 Case 接触次数从 50 降至 25。两种深度的计算成本也不同，四步允许额外循环计算。

## 固定设计与数据用途

- 新训练队列 256 个 Case：174 良性、82 恶性、445 张图，全部来自原 train 分区。选择种子 20261004，比例抽样。
- 原 128 Case（87 良性、41 恶性、227 张图）及其全部视图/标签严格嵌套在新队列中。
- tune 保持 159 Case、281 张图（108 良性、51 恶性），没有扩充或重新选择。cal/test 不编码、不预测、不用于校准或选择。
- 仅末步联合监督分类与分割，独立训练两步、四步 SJ 模型。使用 17、29、43 三个种子，共六次全新拟合；不热启动。
- 这三个种子是为匹配原 128 Case 参照而确定，未根据新结果选择。此前新五种子的复核仍单独保留，不混入这个配对数据规模比较。
- 同一种子的初始权重在两种深度、两种病例规模之间一致。相同规模内两步/四步的病例顺序和视图抽样相同；跨规模顺序与抽样会改变，不能称为相同训练轨迹。
- 新 256 Case 训练 25 epoch，原 128 Case 为 50 epoch。batch size 2，分别为每轮 128 和 64 次更新，最终均为 **3,200 updates、6,400 Case 训练接触**。
- 无增强，冻结 DeiT-Tiny 编码器，缓存完整 224×224 letterbox 特征。学习率 0.0003、AdamW weight decay 0.01，损失、梯度裁剪、模型和核心训练代码不变。
- 714,530 个可训练参数、5,717,416 个冻结编码器参数。两个 CPU worker 各用两个线程，分配互不重叠的三个拟合。
- 新模型每五个 epoch 记录曲线，统一报告第 25 epoch；原参照统一用第 50 epoch，不挑最佳终点。

在新 train 上重新拟合相同常数概率及固定 C=1 的标准化冻结特征线性分类器，不调超参数。新比例 82/256 恰好等于旧比例 41/128；线性模型仍需重拟合，不能拿旧拟合代表新增病例。线性控制先平均视图特征，循环模型平均视图预测，聚合差异保持说明。

## 主要与次要分析

主要量：**G₂₅₆ = Brier（256 Case 独立两步模型最终输出）− Brier（256 Case 独立四步模型最终输出）**，正值表示四步误差更低。

配对次要量：**G₂₅₆−G₁₂₈**，评价深度收益是否随这一固定预算下的数据规模/接触次数变化。另报告每种深度从 128 到 256 的 Brier、NLL、AUROC、Dice 和训练/开发 Brier 差距变化。

逐种子结果全部保留，均值±样本标准差只描述三个拟合。配对 bootstrap 使用相同开发 Case、种子和深度；先在每个 Case 内平均三个种子的效应，再重采样 159 Case，2,000 次，bootstrap 种子 17。区间条件于已训练模型，不包含训练种子总体不确定性，也不把多次预测当成多个患者。

曲线按共同更新次数 **640、1,280、1,920、2,560、3,200** 对齐：新 epoch 5/10/15/20/25，对应旧 epoch 10/20/30/40/50。不能直接用同一 epoch 横向比较，也不为了曲线对齐重训旧参照。

报告固定 0.5 阈值的敏感度/特异度、错误且 p≤0.05 或 p≥0.95 的数量、精确 0/1 概率、独立模型之间的分类纠正/恶化。中间读出未直接监督，不用于替代独立短模型。NLL 保持 epsilon=1e−15 裁剪。

本轮不新增事后硬性成功门槛。依据方向、效应、区间、种子差异及概率/排序/轮廓的取舍作资源判断；不自动启动 585 Case、GPU 或临床验证。

## 复核与公开结果

运行前锁定队列、来源、编码器、manifest、launcher、初始权重、预算及旧协议字节指纹；准备缓存完成后再开 worker。旧六个参照必须逐项验证原配方、队列、初始化和记录。新六次训练核对 25 epoch/3,200 updates，全量逐图记录重算指标，并验证实际 128/256 病例及视图嵌套关系。

Case 与患者身份的对应仍未核实，tune 也已在此前观察。分组、近似重复及外部泛化的限制继续保留。本轮是固定预算的 CPU 探索实验，不能建立临床效用或内部纠错机制。
