# 256 Case CPU 随机种子复核：五个新增配对

执行前方案日期：2026-10-11。上一轮 17/29/43 三个种子的 256 Case 训练已完成；四步的 Brier 收益方向为正、负、正。依据用户本次授权，补齐此前 128 Case 阶段已经使用的 53/71/89/107/131 五个种子。方案在新增模型结果出现前锁定。

## 研究问题与主结果

在已固定的 256 Case、3,200 次更新和末步联合监督条件下，额外共享循环的诊断收益能否在五个新增训练种子上保持？与各自已有的 128 Case 模型相比，数据规模/重复次数变化是否改变这种收益？

主结果只用新增五个种子，每个种子独立训练两步和四步，共十次全新拟合。主要量为 **G₂₅₆ = Brier₂−Brier₄**，正值表示四步概率误差更低。按同一个种子、开发 Case 和深度，配对到已有的十个 128 Case 模型，报告 **G₂₅₆−G₁₂₈**，并分别报告每种深度的 Brier₁₂₈−Brier₂₅₆、NLL、AUROC、Dice 和训练/开发差距变化。

此前三个种子保持独立的历史结果。可以另外汇总全部八个匹配种子，明确标为次要描述；不得用它覆盖新增五个种子的主结果。不重新套用此前 128 Case 的资源筛选门槛，不发明新成功门槛，不自动启动更大规模或 GPU 实验。

## 评估与解释

所有新增模型统一取预定第 25 epoch，参照取预定第 50 epoch，不挑最佳轮次或种子。每五轮记录新曲线，按 640/1,280/1,920/2,560/3,200 updates 对齐旧 epoch 10/20/30/40/50。未直接监督的中间读出只作诊断，不代替独立短模型。

报告逐种子的完整结果、五拟合指标均值±样本标准差、收益正/负数量以及删除任一种子后的平均收益。配对 Case bootstrap 先在每个 Case 内平均五个种子的效应，再重采样 159 Case，2,000 次，bootstrap 种子 17。区间条件于已训练模型，不包含训练种子总体不确定性，不把 5×159 个预测当成独立患者。八种子的次要分析同理。

另外保留固定阈值 0.5 的敏感度/特异度、高置信错误（恶性 p≤0.05 或良性 p≥0.95）、精确 0/1 概率以及分别训练模型间的分类纠正/恶化。NLL 继续用 epsilon=1e−15。较低 NLL 不自动证明校准，较高 Dice 不自动证明诊断或临床效用，独立端点纠正不证明循环内部纠错。

新增种子仍在此前观察过的 tune 上评价。若 G₂₅₆ 比 G₁₂₈ 小，需要检查两步是否更稳定、四步是否退化，而不是直接称为循环失效。曲线差异只提出后续问题，不能据此更换本轮终点或宣称已识别目标冲突。
