# CPU 下一步：概率尺度诊断与末期学习率干预

执行前方案日期：2026-10-11。根据用户授权，完成导师建议的第一、第二步。所有选择在新增校准拟合和训练结果出现前固定。当前核心模型、训练脚本和数据/特征代码保持原样；新功能在独立模块中实现。

## 第一部分：已有模型的病例交叉拟合温度诊断

主分析使用已完成的256 Case训练、53/71/89/107/131五个种子、独立两步/四步、末步联合监督模型，共十个固定终点。它们各自的128 Case十个模型只作配对的次要诊断。全部使用相同159 tune Case、281张图，不新增图像预测，不打开cal/test。

问题：四步排序略好、原始Brier/NLL更差，是否部分与输出概率尺度有关？温度拟合不是新增表征学习，结果不证明内部循环纠错或临床效用。

固定方法：

- 按Case良恶性分层，固定5折、分折种子20261011，所有模型与两种数据规模共用同一分折；同一Case所有视图一起处理。
- 先沿用当前规则平均每Case的全部视图概率，再计算logit。原始Brier保持未裁剪的原概率；输入logit使用epsilon=1e−15以处理0/1。
- 每个模型、每一折仅在其他四折拟合一个正温度T，评估留出折。拟合目标为稳定softplus实现的NLL；log(T)范围固定[-4,4]，一维有界优化，xatol=1e−10、maxiter=1000。
- 候选包含T=1与两个边界。T=1返回原始概率的精确副本；记录边界命中与identity被选的折数，不根据留出折效果挑选T。
- 报告原始与OOF的Brier/NLL、两步/四步收益、逐种子与删除一种子描述，以及AUROC、固定0.5阈值的敏感度/特异度。正温度保留0.5判别方向；不同折的温度可能改变合并OOF排序，因此不能宣称合并AUROC不变或表征被改进。
- 拟合NLL直接使用缩放logit；报告NLL沿用概率epsilon=1e−15裁剪。数值政策分别披露，不能用饱和产生的数值差异包装改善。
- 配对bootstrap在每个Case内平均五个模型种子的效应，再重采样159 Case，2000次，种子17；区间条件于网络、温度拟合和固定分折，不在bootstrap内重拟合温度，也不计训练种子总体不确定性。

执行前锁定网络原始记录、源协议、模块/依赖版本与分折指纹。Case级OOF预测和分折身份保留本地，公开温度参数、指标和汇总。现有tune已被反复观察，本部分是探索诊断，不是独立校准验证。

## 第二部分：共享前缀的末期学习率控制

问题：最后640次更新是否在当前学习率配方下影响四步模型的终点收益？本轮只改变这一项优化器政策，不改变监督位置、损失权重、病例、训练终点或循环模块。

固定256训练Case：174良性、82恶性、445图；开发集仍为159 Case、108良性、51恶性、281图。五个种子与第一部分相同，每个种子分别构建两步、四步SJ模型，从相同于已有模型的初始权重开始。

每个seed/depth先独立训练20 epoch、2560 updates，学习率3e−4。然后保存完整模型、AdamW状态、Python/NumPy/Torch RNG、loader generator及CaseViewSampler epoch=20，从此状态分成两条分支：

| 分支 | 前2560次更新 | 后640次更新 | 固定终点 |
|---|---:|---:|---:|
| constant | 学习率3e−4 | 学习率3e−4 | 3200次更新 / 第25轮 |
| low_tail | 相同前缀 | 学习率固定3e−5 | 3200次更新 / 第25轮 |

这是固定末段阶跃降低，不是学习率网格、余弦方案或事后早停。加载优化器状态后才设置新学习率。每条分支使用独立状态副本，末5轮的病例顺序/视图抽样完全相同；两种深度也使用配对的抽样规则。每条有效轨迹均完成3200 updates、6400次Case接触；四步有额外FLOPs。

总量：10个全新前缀×2560 + 20条末段×640 = **38400次实际新增更新**，产出20条有效完整轨迹的终点；两个政策共用前缀，不是20次独立初始化拟合。两个CPU worker，各两个PyTorch线程，分配互不重叠的五个seed/depth前缀。已有最终checkpoint缺少完整优化器/RNG状态，不用于恢复本轮前缀。

batch size 2、无增强、冻结编码器与既有指纹缓存、学习率以外的AdamW weight decay 0.01、末步分类/分割联合损失、两组梯度裁剪1.0及每五轮评估保持原配方。AdamW的学习率同时影响梯度更新和解耦权重衰减的步长，本轮不能单独识别梯度尺度的原因。

恒定学习率分支必须精确重放对应的已有十个256模型：最终参数张量、训练目标历史、开发历史以及逐图概率/Dice记录完全一致。任何不一致都先作为实现/可比性问题处理，不报告为优化器干预的科学结果。前缀checkpoint和模型/优化器/RNG/采样完整状态均按指纹校验；两步与四步的同形参数也绑定seed/depth，避免误加载。

## 第二部分的指标与解释

定义G_policy = Brier₂−Brier₄。主量 **H = G_low_tail−G_constant**，回答低末期学习率是否更能改善四步。另报告G_low_tail的绝对值、每种深度的constant−low Brier/NLL变化、AUROC、Dice、固定阈值操作点、高置信错误和前缀→终点变化。不能只因两个模型都改善就称为循环特异收益，也不能只因H>0而忽略四步仍不优于两步的情况。

记录每轮训练分类/轮廓损失、裁剪前核心/分割梯度范数与裁剪频率，作为诊断，不据此单独宣称目标冲突或因果机制。前缀与最终的原始Case记录支持配对变化；未直接监督的中间读出保持诊断用途。

所有分支统一使用第25轮，不选择较好的第20轮。bootstrap同上，条件于网络拟合、Case分组与共同队列；逐种子结果完整保留，无新硬性成功门槛、自动扩大病例或GPU阶段。

第一部分和第二部分各自报告，校准诊断不改变第二部分的原始概率主指标。若训练政策改善四步但深度收益仍不稳定，本轮可以帮助收窄后续问题；不是继续搜索学习率直到出现正结果的依据。
